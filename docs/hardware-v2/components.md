# Состав и проверка компонентов

Обновлено: 2026-11-09. Перечень перенесён из ТЗ, а не из проверенного нового заказа.
Для всех позиций актуальные фото, геометрия и способ монтажа ещё не подтверждены.

| ID | Компонент по ТЗ | Что требуется уточнить |
|---|---|---|
| M01 | TENSTAR ESP32-S3-Zero, S3FH4R2, 4 MB flash / 2 MB PSRAM | Ревизия, высота, нижние контакты, схема питания; 18×23,5 мм только по карточке |
| M02 | GPS ATGM336H / AT6558 | Плата, выводы, высота, резервное питание, RF-разъём |
| M03 | Внешняя GPS-антенна и коаксиал | Габариты, ориентация, кабель, разъём и крепление |
| M04 | BME280, 6 выводов, 0x76 | Исполнение, выводы, положение сенсора |
| M05 | GY-521 / MPU6050, 0x68 | INT, ориентация осей, крепление |
| M06 | QMC5883P, 0x2C | Именно P, не L; плата, оси |
| M07 | INA219, 0x40, шунт по ТЗ R100 | Реальный шунт, площадки; в V1 снят клеммник |
| M08 | DS1302 с резервной батарейкой | Плата, тип батарейки, держатель и цепи заряда |
| M09 | Модуль SD/microSD SPI, 3,3 В | Реальное исполнение, контакты, ход извлечения карты |
| M10 | TP4056 USB-C с защитой | Защитный узел, маркировка выводов, ток заряда |
| M11 | TPS63020 / XL63020, выход 3,3 В | Фактическая микросхема, плата, перемычки и характеристики |
| M12 | AO3401, возможно на переходнике | Наличие, выводы, способ монтажа ключа GPS |
| M13 | Один 18650 | Модель, ёмкость, защита, размеры |
| M14 | Держатель 18650 | Новый исправный экземпляр, контакты, удержание батареи |
| M15 | Выключатель с фиксацией, номинально 10 мм | Выводы, панельный монтаж, глубина, ход |
| M16 | Кнопка A без фиксации, номинально 10 мм | Аналогичные параметры |
| M17 | Кнопка B без фиксации, номинально 10 мм | Аналогичные параметры |
| M18 | Пищалка | Тип, напряжение, ток, драйвер, габариты |
| M19 | OLED SSD1306 0,96″ 128×64 | Наличие/заказ, точный модуль и контакты |
| M20 | Встроенный RGB на M01 | По ТЗ GPIO21; отдельная плата не требуется |

Новые разъёмы, крепёж, резисторы, развязка и защитные компоненты добавляются в BOM после выбора.
Их наличие у владельца не предполагается.
