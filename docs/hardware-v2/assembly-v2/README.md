# V2: понятная монтажная инструкция по каждому проводу

16.11.2026. Прямое поручение владельца: заменить непонятные блок-схемы монтажной инструкцией по образцу V1 (`docs/assembly.html`, `docs/wiring.html`). Из V1 взят способ объяснения, не устаревшая распиновка. Сверено с основной веткой c0a6275: s3 0.1.32 / wiring2, GPIO3/7/14, текущая электрическая база. Прошивка не менялась.

**Начать с [index.html](index.html)** — автономная цветная инструкция. Скачать [архив](v2-assembly.zip), распаковать и открыть `index.html` обычным браузером. Интернет странице не нужен.

- [Общая схема SVG](all-wires.svg) / [PNG](all-wires.png): плюс, минус, SDA, SCL и остальные сигналы отдельными линиями. 73 линии с номерами W001–W073.
- [PDF, 5 больших листов](v2-assembly.pdf): общая схема и увеличенные узлы. Векторный формат для увеличения/печати; при печати выбрать подходящий масштаб или постер.
- Крупно: [ползунок и диоды](power-detail.svg), [ключ GPS](gps-detail.svg), [ключ LED LCD](lcd-detail.svg), [адреса/кнопки](straps-detail.svg).
- [Каждый провод в CSV](wires.csv), [машинные данные](wires.json), [генератор](build.py).

HTML содержит всю графику внутри файла. Можно нажать провод или найти его номер: остальные линии станут бледными; сверху покажутся модуль и контакт на каждом конце. Есть масштабирование и таблица всех проводов. Цвет помогает найти сигнал, но соединение определяется контактом и точкой. Пересечение без точки не соединяет провода. Красный пунктир — **сначала проверить, не паять по догадке**.

## Что особенно выделено

- B− батареи и OUT− нагрузки — разные контакты; перемычки между ними нет. На общей схеме каждый плюс и минус нарисован отдельно.
- Две независимые группы ползунка; A/B — кнопки интерфейса. Включение A+B из прежних предложений не возвращено. Полоски обоих 1N4148 смотрят в EN преобразователя; GPIO7 от батарейного EN отделён D2.
- RSW 10 кОм, REN/RB по 100 кОм показаны отдельными элементами. Это ранее предложенные макетные номиналы, не закрытая электрическая приёмка.
- Подсветка: отдельный AO3401, RG 10 кОм, RPU 100 кОм; VCC контроллера LCD не разрывается. Доступ к реальной LED-ветви ещё не установлен.
- Катоды внешних LED идут к площадкам CHRG/STDBY, не к общей земле. Они выделены отдельным цветом; штатные резисторы сохраняются.
- SDA/SCL каждого датчика показаны отдельно. У DS3231 адрес 0x68; у MPU6050 требуется 0x69/AD0 HIGH. GPS TX соединяется с RX ESP32/GPIO44; GPS RX — с TX ESP32/GPIO43.

## Где нельзя сделать вид, что всё уже известно

Рисунки — символы модулей с именами контактов, **не физический порядок площадок**. Его ещё нужно подтвердить по маркировке и прозвонке полученных модулей. Геометрия условная. Формальные PCB netlist/Gerber не создавались.

Не закрыты: связь EN купленного преобразователя с VIN; питание GPS (на карточке есть 5V), точный компас и уровни модулей; штатные подтяжки I2C; площадки подсветки и LED зарядника; модель/ток пищалки и её драйвер; обратное питание от USB ESP32. У пищалки выделен резервируемый вход будущего драйвера, а не выдуманное подключение излучателя к GPIO. GPS RPU показан без утверждённого номинала: V1 использовал 10 кОм, перенос в V2 ещё не принят.

Известные подключения нарисованы полностью; неизвестные не заменены похожей фотографией. Для окончательного монтажа этих участков нужны фото/маркировка/измерения из [E01–E16](../electrical-baseline.md#pre-pcb-checks). После сборки — тестовая SD/OFF посреди записи, reset в ON, реальный rollback. Плата пока не готова к производству.

Основной источник электрических решений — [electrical-baseline.md](../electrical-baseline.md). Инструкция — наглядное представление этих решений; при изменении GPIO/питания обновлять её в той же задаче. Старый комплект `wiring/` сохранён как история отклонённой подачи.

## Проверено

Схемы осмотрены браузером. Проверены выбор/сброс провода, номера, работа на ширине 390/1440 px без переполнения страницы (большая схема прокручивается внутри своей области), отсутствие ошибок JavaScript, 5 одностраничных векторных PDF. Проверка графа соединений подтвердила отдельные цепи B−/OUT−, питания/земли, SDA/SCL, катодов LED/земли; UART перекрещён правильно, VCC/GND восьми узлов и I2C семи участников соединены с соответствующими шинами. [Отчёт интерфейса](checks.json).

Это программная проверка нарисованных проводов, не доказательство работы модулей, корректности footprint или аппаратного power-path. Новых сборок/покупок/изменений прошивки нет.
