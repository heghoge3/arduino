## Исходная база из переданного ТЗ

Эти пункты приняты как база обсуждения. Они не являются новым подтверждением фактического состава заказа.

| ID | Исходное требование | Статус |
|---|---|---|
| B01 | Плата-носитель готовых модулей, ремонтопригодная сборка | Из ТЗ |
| B02 | ESP32-S3-Zero, не C3; сохранить GPIO при отсутствии обоснованного изменения | Из ТЗ; GPIO сверены с двумя версиями кода |
| B03 | Базовое питание от одного 18650 | Из ТЗ; новый аккумулятор/держатель уточняются |
| B04 | Двое суток автономности | Цель из ТЗ, не измеренный результат |
| B05 | Отдельный разъём расширения и сменная высокая крышка | Из ТЗ; конкретные GPIO/монтаж требуют проверки |
| B06 | Кнопки защищены от случайного нажатия; корпус не давит на них | Из ТЗ |
| B07 | BME получает наружный воздух и отделён от нагрева | Из ТЗ |
| B08 | Зоны GPS/BLE-антенн свободны от мешающих элементов | Из ТЗ; точные зоны по реальным модулям |
| B09 | Сервисный доступ к USB, SD, основной и резервной батареям | Из ТЗ |
| B10 | OLED опционален; в последних данных ТЗ не был установлен | Наличие нового OLED уточняется |
| B11 | Старые 100×60×28 мм не обязательный размер V2 | Из ТЗ |
| B12 | PETG — стартовый вариант из ТЗ; PLA — для примерок | Материал владельца уточняется |

## Открытые решения

- Реальный состав заказа, исполнение каждого модуля и установленная прошивка.
- Приоритеты размера, автономности, обслуживания и расширения.
- Экран, размещение кнопок, ориентация на рюкзаке и крепление.
- Требуемые погодные условия, защита и способ доступа.
- Аккумулятор, необходимость замены без инструмента и работы во время зарядки.
- Схема согласования питания USB ESP и внешних 3,3 В.
- Способ подключения нижних площадок S3-Zero.
- Параметры разъёма расширения, доступные сигналы и бюджет питания.
- Производство PCB, бюджет, инструменты и возможности пайки.

Подробные вопросы: [questions.md](questions.md). Пока ответы на все Q01–Q60 ожидаются.

## Правила готовности

Габариты, пины, монтаж и питание должны быть подтверждены до выпуска производственных файлов.
Не обещать IP-класс, срок автономности или точность температуры без соответствующих испытаний.
