## Что готово
- **Прошивка** (`firmware/`, PlatformIO): все модули, BLE-протокол v2 (`docs/protocol.md`), режимы питания,
  защита от подмены, шаги, закат, журнал отладки (`dlog`, `/logs` на SD). Тесты: `pio test -e native`.
  Окружения `s3`, `s3_fake`. Консоль: `help`.
- **Приложение** (`android/`, v0.9.0): Главная, Карта+метки, Графики (восходы/закаты, ночи), Походы,
  Трекер (журнал гаджета и телефона), Настройки (офлайн-карты: схема PMTiles + спутник MBTiles/гибрид).
  Эмулятор гаджета. Тесты: `./gradlew testDebugUnitTest` (скриншоты в `app/build/screenshots`).
- **Документы:** `docs/assembly.html` — схема и пошаговый запуск; `docs/gadget-logic.md`; `docs/backlog.md`.
- **Офлайн-схема:** `tools/map/` (генератор стиля, команда вырезки региона).

## Открытые задачи
1. Спутник: файл Яндекса (проекция EPSG:3395, сдвиг ~18 км) не подходит — Дима скачает другой источник.
   Сначала проверить маленький кусок (1×1 км, z10–18 в нумерации SAS). Дыры в выгрузке закрываются
   через `SatTiles` (локальный сервер тайлов); на телефоне не проверено.
2. Сборка железа по `docs/assembly.html`, замер тока, сутки записи, морозилка.
3. Предложено, не начато: крупный режим «на ходу», короткие тревоги, экспорт GPX/CSV.
4. После похода: счисление по шагам, калибровка компаса, лёгкий сон CPU, поправка температуры,
   Викимапия офлайн (`docs/backlog.md`).

## Сборка
- APK: `cd android && ./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`.
- Тест-векторы протокола генерирует `VectorsTest`; при изменении формата удалить
  `docs/protocol_vectors.json` и перезапустить тесты, затем `pio test -e native`.
