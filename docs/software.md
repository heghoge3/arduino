# Программирование

Исходники: `firmware/` (PlatformIO, ESP32-S3) и `android/` (Kotlin, Android).
По уточнению владельца 10.11.2026 прошивку разрабатывать **только для V2**.
Отдельные задачи поддержки и выпуска V1 не нужны. Прежний аппаратный код сохраняется
как история/основа переноса, но не определяет целевые дисплей, RTC и питание.
Комплект и неизвестные подключения: [электрическая база V2](hardware-v2/electrical-baseline.md).
Версии, артефакты и состояние установки: [STATUS.md](STATUS.md).
Будущее имя продукта: [product.md](product.md); технические имена текущих сборок пока сохранены.

## Сборка

Из firmware/: `pio run -e s3`, `pio run -e s3_fake`, `pio test -e native`.
Из android/: `./gradlew testDebugUnitTest` — проверки JVM; это не испытание на устройстве.
Release: `python3 android/tools/build_signed_apk.py` из корня репозитория с сохранённой
приватной конфигурацией. Подробности в android-signing.md. Debug APK не выдавать как
совместимое обновление release. Сборки запускает исполнитель программной задачи;
изменение документации само по себе не требует новых APK и прошивок.

## Текущее поведение маршрута

Принятые GPS-точки дают маршрут; без доверенного GPS сохраняются шаги и датчики.
Пунктир между привязками не восстанавливает неизвестные повороты.
Гироскоп и постоянные измерения компаса в текущем экономичном варианте отключены.
Желаемый компас/трек на новом LCD — задача V2, не обещание уже готовой функции.
Телефон и время сами по себе не объявляют GPS подменённым; ожидание восстановления
отделено от обнаруженной подмены. Подробные алгоритмы — в коде и разборе журналов.
