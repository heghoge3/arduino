# Чек-лист: сборка 29–30.10 и поход 31.10

## Сборка (по одному модулю, `docs/assembly.html`)
1. `git pull origin ccr-faf69fbe-vwugry`, прошивка **`s3`** (не fake).
2. Питание без платы: на выходе TPS63020 3,25–3,40 В (не 4,2 / 5 В!). Минус аккумулятора — только на B− TP4056.
3. По одному: OLED → BME280 → MPU6050 и компас → DS1302 → SD → GPS. После каждого `i2c` / `st` / `info`.
4. DS1302: подключить телефон (время), выдернуть USB на минуту, `st` — время идёт; поход продолжается.
5. Ключ GPS: мультиметр D–GND, «Выкл GPS» ≈ 0 В, «Вкл GPS» 3,3 В — только потом модуль.
6. GPS на улице/у окна: `gps echo`, фикс 1–5 мин. Записать, какие системы в GSV (GP/BD/GL).
7. USB и аккумулятор вместе — НЕЛЬЗЯ. Прошивать только при выключенной кнопке питания.

## Если не успел всё
Гаджет от пауэрбанка через USB-C (без TP4056/INA219/TPS63020). Без SD — трек только в памяти,
пропадёт при перезагрузке: тогда чаще подключать телефон (он забирает точки).

## Вечер перед походом
- Зарядить LiPo / 18650 и пауэрбанк. SD FAT32 вставлена, в `info` видна.
- Телефон: XOS — батарея «без ограничений», автозапуск, приложение закреплено; Bluetooth и геолокация вкл.
- Открыть приложение с интернетом — обновится погода (в окошке должно быть место).
- Подключиться к гаджету дома: время проверено (`доверие=1`), новый поход начался.

## В походе
- Гаджет — второй, основной трек на телефоне (ТЗ).
- Метка — кнопка A / в приложении; хлопушка перед съёмкой нескольких камер.
- Машина/электричка: «Выкл GPS», потом «Вкл GPS» — переезд не попадёт в трек и километры.
- Раз в несколько часов открыть приложение — точки докачаются, видно заряд.
- Если что-то странно — Гаджет → Журнал → «Поделиться», сохранить файл для разбора.
