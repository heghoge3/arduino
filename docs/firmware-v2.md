# Прошивка V2: перенос и условия первого запуска

10.11.2026. Единственная целевая компоновка — V2. Исходники 0.1.25, не выпуск для
установки. Android 0.10.4 сохраняет прежний контракт цикла, изменений APK этим этапом нет.

Актуальная GPS-обработка: [политика 2](gps-policy-v2.md), нужна пара с APK 0.10.6.

## Реализовано в коде

- DS1302 удалён из аппаратного драйвера. DS3231 использует общую I2C, адрес 0x68,
  проверку BCD/календаря и OSF (остановка генератора). Свежий модуль не объявляется
  источником проверенного времени и не переписывается временем сборки. Доверие
  сохраняется в NVS rtc-v2 только после записи времени от телефона/GPS и чтения
  обратно. Ошибка записи не даёт доверия RTC при следующем холодном запуске.
- MPU6050 ожидается на 0x69 (AD0 HIGH), с проверкой WHO_AM_I. По 0x68 конфигурационные
  команды MPU не отправляются. В RTC-драйвере добавлен отказ при ответе WHO_AM_I MPU
  на 0x68; это защитная проверка, не универсальная идентификация DS3231.
- SSD1306 заменён на драйвер ST7567, кандидат профиля U8g2 JLX12864. Для LCD
  проверяются 0x3E/0x3F; единственный ответ выбирает адрес, два ответа дают отказ
  от инициализации. ACK не доказывает модель экрана. Профиль инициализации,
  ориентация, контраст и смещение требуют проверки именно на GM12864-59N.
- Общая I2C запускается до часов, на 100 кГц, с таймаутом. Зуммер по умолчанию
  пассивный: PWM с изменяемой частотой вместо постоянного HIGH.
- START/END/RESUME, восстановление и история сохранены. Меню отрисовывается новым
  драйвером; любая кнопка будит изображение, через 15 секунд гасится изображение LCD.
  **Это пока не управление подсветкой**: её схема и вывод неизвестны.

## Подготовленное управление питанием

По поручению владельца выбран **GPIO7 для HOLD**, включён по умолчанию в 0.1.23.
После удаления DS1302 вывод не занят; ESP32-S3 поддерживает для него RTC hold.
Это программное назначение, а не подтверждение монтажа/испытаний экземпляра платы.
Подключение: GPIO7 → анод D2 (1N4148); катод D2 к общей точке EN по выбранной схеме.
Не подключать GPIO7 непосредственно к батарейному START или к EN в обход D2.
Подсветка LCD ещё не назначена. Для стенда от независимого питания без узла EN
задать `V2_POWER_HOLD_PIN=-1`; в этом режиме жест запуска и пункт выключения отключены.
По умолчанию прошивка теперь требует штатный жест A+B, в том числе при USB-питании.

В коде подготовлен путь для последующей конфигурации проверенного HOLD:

1. При холодном запуске HOLD выключен. Непрерывное A+B около четырёх секунд даёт
   четыре нарастающих сигнала. Прерывание комбинации обнуляет выдержку. HOLD
   устанавливается перед последним сигналом; после отпускания открывается обычная
   работа без автоматического начала похода. Только A может физически держать
   пробное питание — это свойство выбранной схемы, программно его не устранить.
2. Внутренний сон удерживает уровень RTC GPIO. При пробуждении уровень восстанавливается
   до снятия фиксации. Пробуждение не требует нового жеста; ошибка фиксации отменяет сон.
3. Меню «Выключить прибор» для ACTIVE/RECOVERY спрашивает «Завершить поход?».
   A переключает «Да/Нет», новое удержание B 1,5 с подтверждает; длинное A отменяет.
   «Да» выполняет устойчивый END; «Нет» сбрасывает хвост и сохраняет незавершённый
   статус для вопроса о продолжении после следующего включения. Ошибка сохранения
   не разрешает обычное отключение. Для IDLE/ENDED подтверждается только выключение.
4. После сохранения требуется стабильное отпускание обеих кнопок, затем снимается HOLD.
   Если USB/обратное питание оставили ESP32 работающим, выводится «Питание не снято»
   и запись не возобновляется. Глубокий сон не используется как замена выключению.

Выбран GPIO7. После уточнения владельца GPIO45, 42, 41, 40, 39, 38, 18, 17, 16,
15 и 14 исключены из внешних подключений V2: это труднодоступные площадки на фото
платы. Ни один из них сейчас не используется. GPIO14/15 раньше были линиями DS1302;
этот драйвер удалён. Переносить текущие назначения не требуется.
В pins.h добавлена проверка сборки против использования этих площадок; HOLD допускает
только GPIO7 либо -1 для стенда. Альтернативы GPIO14–18 отменены.
Проверить площадку с маркировкой 7/IO7 на конкретной S3-Zero, уровни при boot/reset,
подтяжки, HOLD во сне и USB-развязку на макете. Не путать GPIO7 с порядковым номером ножки.

## Программный интерфейс и неизвестные сведения

| Связь | Текущий код / требование к проверке |
|---|---|
| I2C | GPIO8 SDA, GPIO9 SCL — сохранённые прежние назначения, сверить с монтажом V2 |
| DS3231 | Общая I2C, 0x68; резервное питание и отсутствие нежелательного заряда проверяет аппаратный этап |
| MPU6050 | Общая I2C, 0x69; AD0 HIGH обязателен для этой конфигурации |
| LCD | 0x3E либо 0x3F; фактический адрес, профиль и подсветка пока не подтверждены |
| Кнопки A/B | GPIO1/2, вход активен LOW; A читается через согласованную транзисторную развязку, не с батарейного START напрямую |
| Зуммер | GPIO5, PWM; электрический драйвер и допустимый ток экземпляра проверить |
| HOLD | GPIO7, HIGH удерживает питание; через D2 к EN, включён в конфигурации |
| GPS/SD/INA/компас | Сохранены прежние программные назначения; соответствие реальным модулям V2 не объявлено проверенным |

Источник аппаратных ограничений — [электрическая база](hardware-v2/electrical-baseline.md)
и [кнопочное питание](hardware-v2/button-power-selection.md). Этот документ задаёт
программную реализацию, не утверждает разводку или покупки.

## Проверки и оставшаяся работа

Native: 60 тестов, включая календарь/12-часовой формат/невалидные регистры DS3231,
непрерывное A+B и переполнение millis. Сборки s3/s3_fake проверяются для V2;
это не аппаратная проверка и не доказательство правильного изображения LCD.
Android не изменён; прежние 135 тестов относятся к этапу 0.10.4 и здесь не повторялись.

До автономного запуска остаются: подключение и проверка HOLD, назначение подсветки, проверка адреса/профиля
LCD на экземпляре, реальная I2C/AD0 и зуммер, сохранение уровня HOLD во всём цикле сна,
отключение при «Да/Нет», ошибки SD и обрыв питания. Нужна проверка, что ESP32/GPS/SD/
экран действительно после отключаемого выхода и нет подпитки от USB/сигнальных линий.
Пока эти условия не выполнены, не выдавать исходники 0.1.23 за готовую к установке V2.
