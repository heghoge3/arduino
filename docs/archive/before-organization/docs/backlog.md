# Идеи на потом

## Викимапия офлайн (запрос Димы, 26.10)
В походах часто нужна Викимапия, а интернета нет.
- API живой (`api.wikimapia.org`), данные CC BY-SA — можно хранить у себя с указанием источника.
- `function=box` по рамке отдаёт название, контур, ссылку; в центре СПб ~400 объектов на 1 км².
- Описания, вероятно, только поштучно (`place.getbyid`), а у API лимит запросов → качать описания
  только для выбранных категорий (заброшенное, военное, промзона, руины) и районов.
- Нужен свой бесплатный ключ API (wikimapia.org/api) — у Димы.
- В приложении: файл слоя в «Настройки → Офлайн-карты», контуры и подписи поверх схемы/спутника,
  тап — карточка с описанием.
