# Откат интерфейса: 0.10.11

15.11.2026 владелец отклонил переработку 0.10.10 и поручил вернуться к предыдущей версии. Восстановлены все изменённые Android-файлы из состояния опубликованного 0.10.9 (дерево 00732dc): исходный тёмно-синий фон, название/логотип, компоновка, настройки, карта и прежние действия. Отменена также промежуточная замена фона из 89ab171.

Единственное отличие Android-кода от этой базы — versionName 0.10.11 / versionCode 34. Это позволяет обновить установленный 0.10.10 обычной установкой с прежним сертификатом; ставить старый APK с меньшим code или удалять приложение не требуется. Схема данных, package ID, ключ подписи и OTA-образ не меняются. Новые настройки оформления 0.10.10 не читаются прежним кодом; сохранённые походы и данные не удаляются.

Ответы 1–50, отклонённые предложения и коммиты сохранены как история. Новую реализацию дизайна не начинать без отдельной задачи. Откат не является исправлением DIST1, GPS или аппаратной приёмкой.

Проверки: весь набор Android JVM/Robolectric **164 теста, 0 провалов**. Сравнение дерева `android/` с 00732dc подтвердило побайтовое совпадение всех файлов, кроме двух строк версии Gradle. Release APK собран, apksigner подтвердил прежний закреплённый сертификат. Проверены code34 / 0.10.11 и побайтовое совпадение трёх OTA-ресурсов.
