# LCD целиком через AO3401 — исходники 0.1.33 / wiring3

Прямое поручение владельца: доработать прошивку под выбранное отключение всего VCC дисплея. Пакет/дизайн Android не меняются. Исходная база 3c86f73, основной s3, GPIO14 LOW=ON / HIGH=OFF, S=SYS_3V3, D=LCD VCC, RG10к и RPU100к. Схема остаётся макетной, I2C off-state ещё не принята.

## Реализовано

- Последний найденный адрес сохраняется в RTC-памяти через deep sleep; OFF не переобъявляется отсутствием. Перед новым изображением всегда свежий probe.
- Холодный старт и пробуждение кнопками подают питание перед первым I2C probe. Таймер/движение/ползунок OFF не включают LCD только ради обнаружения; ночных периодических вспышек код не запрашивает.
- После каждого OFF (включая выключение внешним OTA/reset-путём) следующий запрос экрана заново подаёт VCC, выдерживает интервал, проверяет единственный адрес 0x3E/0x3F, выполняет полный U8g2 begin и передаёт кадр. Кэш готовности недействителен при логически выключенном GPIO-драйвере.
- После OFF нет setPowerSave/sendBuffer или probe адресов LCD. Сканер/пересканирование датчиков не обращаются к адресам LCD при отключённом ключе. Остальная I2C работает; это НЕ электрическая развязка сигналов дисплея.
- Сохраняются 15 с бездействия, wake любой кнопкой и поглощение первого жеста, RTC HIGH при сне/reset, GPIO7 HOLD и цикл похода. При отсутствующем/неоднозначном адресе или отказе драйвера ключ выключается, повторное включение может повторить init. UI ожидает дисплей V2 даже после пропущенного probe на таймерном wake.
- `LCD_POWER_SETTLE_MS=50` — консервативный **макетный** интервал перед probe/init, не подтверждённая задержка из паспорта полученного модуля. Измерить фронт VCC, POR и первую транзакцию; при необходимости изменить.

## Совместимость OTA

Ревизия **wiring3** отделена от LED-only wiring2. Приёмник отвергает манифесты wiring1/2 до стирания; namespace состояния OTA — `ota-v2-r3`, старые `ota-v2`/`ota-v2-r2` не удаляются и не исполняются. Ключи и разметка не изменены. Пакетировщик по умолчанию подписывает только wiring3, `--wiring 2` оставлен явно для истории; проверка публичного пакета допускает известные 2/3 с точным совпадением metadata/подписи, не разрешая переход между ними приёмнику.

Старый APK 0.10.11 содержит прежний образ 0.1.32/wiring2 и не подготовлен для обновления новой ревизии. Его ресурс прошивки не заменён. Готового опубликованного подписанного OTA/USB-комплекта wiring3 в этой задаче нет. Переход с уже установленной wiring2 требует отдельного USB-плана/двух приватных копий flash; нельзя просто оставить несовместимый старый слот в роли принятой rollback-базы. Сборка s3_ota_bootstrap имеет тег 0.1.29, но теперь wiring3 — номер 0.1.29 один не определяет совместимость.

## Проверки

Новые 6 native-сценариев: порядок power→settle→probe→init, отсутствие повторного init при непрерывном ON, OFF без I2C и повторный init, внешнее отключение, отсутствующий/неоднозначный LCD с retry, отказ GPIO/инициализации. Сохранены проверки затвора/RTC/кнопок/15 с, OTA проверяет отказ wiring1 и wiring2. 110 native, 12 compile probes, 4 host power regression, 4 OTA-tool tests прошли. Четыре сборки **s3 / s3_fake / s3_ota_bootstrap / s3_slider_bench прошли**. [Размеры, SHA-256 и metadata](2026-11-16-lcd-builds.json) проверены непосредственно в бинарниках; основной s3 — 764896 байт, версия 0.1.33, wiring3. Размер сам по себе не доказывает работу OTA/железа.

## Обязательное на V2

Проверить активные SDA/SCL при VCC=0 по схеме/допустимым уровням полученного LCD и измерить подпитку. Если модуль не допускает такой режим, нужна аппаратная изоляция; её код не заменяет. Проверить многократные 15-секундные циклы и обе кнопки, POR/контраст/ориентацию, таймерный и motion wake без включения LCD, сон/RTC hold, OFF/SD и reset/OTA. На физическом устройстве эти испытания не выполнены; прошивка программно адаптирована, весь узел аппаратно не принят.
