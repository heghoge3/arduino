# Логика работы устройства и связи с телефоном

Согласовано с Димой 26.10. Прошивка и приложение реализуют именно это.
Протокол байтов — в [protocol.md](protocol.md).

Главный принцип: **устройство работает без телефона.** Оно само пишет трек, датчики и метки на SD.
Телефон — окно (посмотреть), пульт (команды) и источник времени и своей позиции.
Радио почти всё время молчит.

## 1. Состояние устройства = питание × GPS × радио

### 1.1 Питание

| Состояние | Код | Вход | Что делает |
|---|---|---|---|
| Стоянка | `CAMP` (0) | нет шагов `CAMP_AFTER_S` (5 мин); старт после включения | GPS выкл. Глубокий сон, пробуждение по таймеру: датчики раз в `LOG_CAMP_S` (60 с), маячок раз в `BEACON_CAMP_S` (60 с). Записи копятся в RTC-памяти и сбрасываются на SD раз в 15 мин или при заполнении |
| В пути | `MOVING` (1) | акселерометр: прерывание движения + ≥ `STEPS_TO_MOVE` (10) шагов за 30 с | GPS по режиму (§1.2). Запись раз в `LOG_MOVING_S` (10 с). Счёт шагов. Маячок раз в `BEACON_MOVING_S` (30 с) |
| Экономия | `ECONOMY` (2) | заряд < 15 % (выход > 18 %) | Как в пути/стоянка, но GPS только импульсами, запись раз в 60 с, маячок раз в 120 с |
| Критический | `CRITICAL` (3) | заряд < 5 % (выход > 8 %) | GPS и радио выкл (кроме одной тревоги). Только температура/давление раз в 300 с. Экран не включается |

Пробуждение из сна: таймер; кнопки A/B (GPIO1/2); прерывание движения MPU6050 (GPIO4).

### 1.2 GPS

`OFF` → `SEARCHING` → `FIX` → `OFF`.

- Режим **«всегда»** (по умолчанию): включён всё время в состоянии «в пути».
- Режим **«импульсы»**: включается раз в `GPS_PULSE_S` (30 с), ждёт фикс (до 20 с, горячий старт обычно 1–5 с), берёт 3 точки и выключается.
- При выключении UART-пины в INPUT (ТЗ, раздел 2), батарейка горячего старта сохраняет эфемериды.

### 1.3 Радио

| Состояние | Когда | Что |
|---|---|---|
| Тишина | по умолчанию между маячками; режим «невидимка» (период маячка = 0) | радио выключено |
| Маячок | раз в 30 с (в пути) / 60 с (стоянка) / 120 с (экономия) | ~300 мс рекламы с интервалом 50 мс, данные сводки (§2). К нему можно подключиться |
| Окно | долгое нажатие B; тревога | 2 мин рекламы с интервалом 100 мс |
| Сеанс: живой | телефон подключился и прислал `SESSION live` | STATUS раз в секунду, SATS раз в 5 с, новые POINT/MARK сразу |
| Сеанс: тихий | `SESSION quiet` (приложение свернуто) | только MARK и ALERT; параметры связи с большой задержкой |

Тайм-ауты сеанса: устройство само рвёт связь, если от телефона ничего не было `SESSION_TIMEOUT_S` (60 с).
Приложение шлёт `SESSION` каждые 20 с как «я тут». `BYE` — отключиться сразу.
После сеанса — снова маячок по расписанию.

## 2. Маячок

Сводка без подключения, **без координат** (эфир слышит любой телефон рядом; координаты не нужны — в радиусе
приёма устройство там же, где телефон). Формат — protocol.md, «Маячок».
Внутри: режим, температура, заряд, спутники, давление, флаги (запись, фикс, подмена, тревога, время проверено),
время последней записи (телефон понимает, есть ли новое), номер похода.

Функция «где устройство»: приложение запоминает **свою** позицию в момент последнего принятого маячка.

## 3. Тревоги

| Тревога | Когда | Повтор |
|---|---|---|
| Подмена GPS | начало эпизода подмены (держится минуту после последнего подозрительного фикса) | см. ниже |
| Низкий заряд | переход ниже 15 % | см. ниже |
| Критический заряд | переход ниже 5 % | см. ниже, затем радио выкл |
| Ошибка SD | запись не удалась | см. ниже |

Устройство открывает окно (2 мин) с флагом тревоги в маячке, пищит и мигает (подмена — коротко, заряд — длинно).
Если тревогу не подтвердили (`ACK_ALERT`), повторяет окно раз в 10 мин, максимум 3 раза.
Во время сеанса тревога приходит сообщением ALERT сразу.

## 4. Время

Порядок доверия: телефон (`SET_TIME` при каждом подключении, заодно поправляет DS1302) → DS1302 → GPS без подмены.
Если DS1302 стоял (села батарейка) и времени ещё нет — флаг «время не проверено» в STATUS и маячке.

## 5. Приложение

| Состояние | Что делает |
|---|---|
| Закрыто, наблюдение выкл | ничего |
| Фоновое наблюдение | сервис с постоянным уведомлением; аппаратный фильтр сканирования по маячку (дёшево). Уведомление «2,3° · 80 % · GPS ок · 3 мин назад». Флаг тревоги → отдельное уведомление со звуком. Запоминает свою позицию при каждом маячке |
| Открыто → поиск | активное сканирование до первого маячка (≤ 60 с); подсказка «нажмите долго B», если не слышно |
| Подключение и синхронизация | MTU 247 → `SET_TIME`, `PHONE_POS`, `BLACKLIST` → `GET_INFO` → `SYNC_TRACK/SYNC_MARKS` с последней известной записи → `SESSION live` |
| Живой | STATUS раз в секунду, `SESSION` каждые 20 с |
| Свёрнуто | через 30 с `SESSION quiet`, через 2 мин `BYE` |
| Офлайн | последние сохранённые данные + «на связи N мин назад» |

Всё принятое сохраняется в локальной базе телефона: открыл приложение — сразу видно последнее состояние.
Кнопка «Обновить» на главной — подключиться сейчас (если слышен маячок).

## 6. Оценка потребления (проверить замером INA219)

| | Ток |
|---|---|
| GPS | ~25 мА |
| Процессор в пути (80 МГц, без лёгкого сна) | ~15–20 мА — **риск**, с автоматическим лёгким сном меньше |
| Сон всей платы | 0,05–3 мА — зависит от SD-карты и RGB-светодиода WS2812 |
| Маячок 300 мс раз в 30–60 с | ~0,3–0,7 мА (с запуском BLE-стека после сна) |
| Живой сеанс | ~15–25 мА, только пока смотришь в телефон |

Если «в пути» выйдет больше бюджета — включать GPS импульсами (настройка в приложении).
