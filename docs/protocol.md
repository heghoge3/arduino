# Протокол BLE vabuGEOde — версия 1

Общий для прошивки (`firmware/`) и приложения (`android/`). Любое изменение формата —
сначала здесь, потом в обоих местах, потом обновить тест-векторы `docs/protocol_vectors.json`.

## GATT

| Что | UUID | Свойства |
|---|---|---|
| Сервис | `e0f30001-5642-4744-8a1e-76616275676f` | |
| Status | `e0f30002-5642-4744-8a1e-76616275676f` | notify, read |
| Command | `e0f30003-5642-4744-8a1e-76616275676f` | write (с ответом) |
| Event | `e0f30004-5642-4744-8a1e-76616275676f` | notify |

`5642 4744` = «VBGD», `76616275676f` = «vabugo».

- Инициатор подключения — телефон. Устройство только рекламируется (имя `vabuGEOde-XX`).
- После подключения телефон **обязательно** запрашивает MTU 247. Самый длинный пакет — 99 байт,
  при MTU 23 пакеты не пролезут.
- Сопряжение (bonding) обязательно: команды от несопряжённого телефона устройство отклоняет.

## Общие правила

- Порядок байт — **little-endian**. Чисел с плавающей точкой нет, только целые с масштабом.
- Байт 0 — версия протокола (`1`), байт 1 — тип сообщения или команды.
- Устройство отвечает на неизвестную версию событием `ACK` с `result = 3`.
- «Нет данных» для знаковых 16-битных полей — `0x8000` (−32768), для `hdop` — `255`.
- Время — Unix-секунды UTC (`u32`).
- Координаты — градусы × 10⁷ (`i32`). `0, 0` = нет координат.

## Характеристика Command (телефон → устройство)

Байт 0 — ver, байт 1 — код команды, дальше аргументы. На каждую команду устройство отвечает `ACK`.

| Код | Команда | Аргументы |
|---|---|---|
| 0x01 | SET_TIME | u32 time_utc, i16 смещение пояса, мин |
| 0x02 | PHONE_POS | i32 lat, i32 lon, u16 точность, м |
| 0x03 | RECORD | u8: 1 старт, 0 стоп |
| 0x04 | MARK | u8 mark type, u8 L, L байт текста UTF-8 (≤ 60) |
| 0x05 | CLAP | — (писк + вспышка + метка SYNC) |
| 0x06 | FIND | — (писк) |
| 0x07 | SET_INTERVALS | u16 в движении, с; u16 на стоянке, с |
| 0x08 | CALIB_ALT | i16 известная высота ×10 м |
| 0x09 | CALIB_COMPASS | u8: 1 старт, 0 стоп |
| 0x0A | BLACKLIST | u8 N, затем N × (i32 lat, i32 lon, u16 радиус м); N ≤ 24 |
| 0x0B | GET_INFO | — |
| 0x10 | SYNC_TRACK | u32 since_utc — прислать POINT начиная с этого времени |
| 0x11 | SYNC_MARKS | u32 since_utc — прислать MARK начиная с этого времени |

## Порядок при подключении

1. Телефон: MTU 247, подписка на Status и Event.
2. `SET_TIME` (время телефона), `PHONE_POS` (если есть геолокация).
3. `GET_INFO` → `INFO`.
4. `SYNC_TRACK(последняя известная точка)` → поток `POINT` → `SYNC_DONE`.
5. `SYNC_MARKS(...)` → поток `MARK` → `SYNC_DONE`.
6. Дальше устройство само шлёт `STATUS` раз в секунду, `SATS` раз в 5 с, новые `POINT` и `MARK` по мере записи.
