# Продукт: действующие решения

Источник: последние уточнения владельца в чате, сохранённые при реорганизации.
Этот документ — единственное основное место для названия, аудитории и коммерческой цели.

## Название

Название ещё не утверждено. «Полимер» — рабочий кандидат, владелец может его изменить.
Устройство и приложение будут называться одинаково. Старое название будет заменено.
Из этого решения не следует немедленное изменение package ID, ключа подписи или
маркировки ещё не спроектированного корпуса: такие изменения — отдельная задача.

## Для кого и зачем

Основная аудитория первой коммерческой версии — люди, которые ходят в походы.
Прибор записывает маршрут, метки и показания датчиков, позволяет просматривать
их в Android-приложении; автономность и надёжность важны для использования в походе.
Прибор начинался как личный проект, коммерческая версия — явная цель развития.
Отдельное позиционирование для городских исследователей и велосипедный сценарий
не входят в утверждённый объём первой коммерческой версии.

## Порядок развития

1. Довести функционирующий прототип, проверить его в реальных походах.
2. На основании испытаний доработать конструкцию, функции и удобство приложения.
3. Подготовить понятный и надёжный продукт для массового пользователя и продажи.

Это последовательность этапов, не утверждённый календарь запуска. Цена, объём партии,
каналы продаж, гарантии и окончательный набор коммерческих функций пока не определены.
Владелец рассматривает свои каналы, в том числе Telegram, для первых проб продвижения.
Не обещать покупателям автономность, точность, влагозащиту или ударостойкость,
которые ещё не подтверждены испытаниями готового изделия.

## Кто принимает решения

Общие требования и изменения направления утверждает владелец. Каждый из трёх чатов
обсуждает задачу с ним отдельно и выполняет согласованный объём. Порядок и границы
направлений описаны в [совместной работе](collaboration.md).
