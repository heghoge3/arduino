# Цикл похода: устройство, две кнопки и приложение

Проект спецификации от 10.11.2026. Основа — основная ветка `9641852` и повторная
сверка исходников. Владелец разрешил **проработку и документирование**, не кодирование.
Разделение включения и начала похода — заданное направление; подробные переходы,
раскладка кнопок и варианты выключения ниже **предложены для согласования**.
Общая очередь задач остаётся в [software-roadmap.md](software-roadmap.md), этап S4.

## Состояния и понятный следующий шаг

Поход, связь, качество GPS и успешность сохранения — независимые сведения.
Устройство подтверждает жизненный цикл; телефон хранит последнее известное
состояние и его свежесть. Временная потеря BLE ничего на приборе не завершает.

| Ситуация | Экран устройства | Экран приложения и действие |
|---|---|---|
| Включено, открытого похода нет | «Готов к походу» → «Начать поход» | После получения свежего состояния — то же действие; до этого «Проверяем состояние устройства» |
| Начало запрошено | «Начинаем…»; повтор недоступен | «Ожидаем подтверждения начала»; не рисовать начавшийся поход до результата |
| Поход активен, запись исправна | «Поход записывается», длительность; GPS отдельной строкой | Текущий поход, свежие данные, «Метка», «Завершить поход» |
| GPS ещё ищется/недоступен/подозрителен | Поход остаётся активным; понятный статус координат | Датчики/шаги доступны по действующим правилам; пропуск трека обозначен, неизвестные координаты не дорисовываются. Политика подмены — отдельная задача |
| Пропал BLE или телефон перезапущен без связи | Запись на устройстве продолжается, если оно работает | «Нет связи. Последнее подтверждение записи: …» и сохранённые данные; текущая работа прибора неизвестна |
| Выполняется завершение | «Сохраняем поход…» | «Ожидаем подтверждения завершения»; повторное нажатие не создаёт другую операцию |
| Завершение устойчиво сохранено | «Поход завершён» → итог, меню или выключение | Поход в истории; отдельно «Данные полностью получены» либо «Осталось получить данные» |
| Штатное выключение до продолжения, если Q2 принят | Перед отключением «Сохранено. Поход можно продолжить» | «Поход приостановлен до продолжения» только по подтверждённому результату. Это не завершённая история |
| Обнаружена незакрытая запись после сбоя/разрядки | «Незавершённый поход» → «Продолжить» / «Завершить» по предлагаемому Q1 | «Запись прерывалась. Требуется решение» после получения состояния |
| Ошибка SD/сохранения | «Запись не сохраняется» или «Не удалось завершить»; повтор/диагностика | Та же ошибка, если получена от прибора; не писать «Всё сохранено» |
| Прибор отключён месяц, ответа о завершении не было | Экран обесточен | Главная с подключением и карточкой «Последний поход: завершение не подтверждено». Графики открываются как сохранённая запись, не выглядят живыми |

Завершённый поход — запись истории. Прибор после экрана итога может перейти в
готовность, сохранив ссылку на последний итог; это не автоматическое продолжение.
Графики доступны офлайн. Недосинхронизированные данные не делают завершённый поход
активным, а получение всех точек само по себе не доказывает завершение.
Без связи приложение не запускает «живой» таймер по кэшу и не выдаёт сохранённые
показания за текущие. Возраст записи меняет её представление, но не подтверждает
окончание; для этого не нужен таймер автоматического завершения через месяц/6 часов.

## Предлагаемое управление двумя кнопками V2

A/B — логические имена; расположение слева/справа пока не назначено.
На каждом экране короткая подсказка действий. Длительности ниже — стартовые
предложения для проверки удобства, не окончательные значения.

| Контекст | A | B |
|---|---|---|
| Прибор выключен | Совместно A+B удерживать около 4 с: четыре нарастающих сигнала; после успеха отпустить обе кнопки | Тот же жест включения; поход не начинается |
| Главная активного похода | Коротко — следующая страница данных | Коротко — меню похода |
| Меню | Коротко — следующий пункт по кругу; удержание около 1 с — назад | Коротко — выбрать пункт |
| Подтверждение начала/завершения/выключения | Коротко — отменить | Новое удержание около 2 с с видимым отсчётом — подтвердить |
| Экран погашен/кнопки заблокированы | Первое нажатие показывает статус и подсказку; ничего не выполняет | То же |

Предлагаемая разблокировка работающего прибора — A+B около 2 с, затем отпустить
обе кнопки. Она не меняет запись и не выключает устройство. После примерно 30 с
бездействия — возврат на статус и блокировка; подтверждение отменяется, уже принятая
операция сохранения продолжает выполняться. Экран/подсветка гаснут только в пределах
возможностей проверенного LCD. Блокировка не является отключением питания.

Минимальные пункты меню:

- Без открытого похода: «Начать поход», «Последний поход», «Телефон», «Настройки», «Выключить».
- В активном походе: «Поставить метку», «Завершить поход», «Телефон», «Настройки», «Выключить».
- При ожидании продолжения: «Продолжить поход», «Завершить поход», «Выключить».

Метка ставится выбором пункта без дополнительного подтверждения, только в активном
походе; успех сообщается после сохранения, при ошибке — ошибка. Для быстрого доступа
меню активного похода открывается на «Поставить метку». Прежнюю хлопушку переносить
в отдельное действие меню/приложения, не вызывать старым длинным A поверх нового меню.
Сопряжение нового телефона доступно через «Телефон» с явным действием; существующий
жест B удержанием не должен одновременно подтверждать выключение и открывать сопряжение.
Полный состав настроек, хлопушка и энергосбережение вне утверждения этого этапа.
На LCD 128×64 список прокручивается, длинные пункты переносятся на две строки;
сокращение не должно скрывать разницу между завершением и выключением до продолжения.

При входе на подтверждение дождаться отпускания кнопок; удержание, которым открыли
экран, не засчитывается повторно. A+B обрабатываются как один жест и поглощают
одиночные события A/B. Незавершённый отсчёт не выполняет действие. Это снижает риск
случайных действий, но долгое давление на обе кнопки в рюкзаке всё ещё возможно.

У [выбранной EN-схемы](hardware-v2/button-power-selection.md) A одна временно подаёт
питание. До подтверждения A+B нельзя менять журнал похода, ставить метки или начинать
запись. После подтверждения HOLD устанавливается до сообщения об успешном запуске.
Постоянно зажатая A может удерживать питание независимо от прошивки.

## Начать, закончить, выключить

**Начало.** Явный запуск с меню либо подключённого приложения → проверка отсутствия
другого открытого похода и исправного хранения → устойчивое начало → подтверждение.
Ожидание GPS не блокирует начало: запись начинается без выдуманной первой координаты.
Недоступная/полная SD блокирует старт с объяснением. Готовность не создаёт файл похода
и не накапливает его дистанцию; предварительная диагностика датчиков допускается.

**Завершение с прибора.** Меню → «Завершить поход» → новое удержание B → сохранение →
итог. **С телефона:** отдельная кнопка → диалог подтверждения → команда → подтверждённый
итог. Приложение не обязано оставаться открытым для завершения на устройстве.
Без BLE команда недоступна и автоматически на будущее не ставится в очередь.
Локальная пометка «Я закончил» (Q4) в первую версию этого сценария не включена.

**Выключение без открытого похода.** Меню → подтверждение → сохранить настройки →
дождаться отпускания A → снять HOLD. Для записи в процессе сохранение обязательно;
неподтверждённую ошибку не превращать в успешное выключение.

**Выключение с открытым походом — Q2.** Предлагается экран выбора:
«Завершить и выключить» / «Выключить до продолжения» / «Отмена». Первый вариант
устойчиво закрывает поход. Второй сохраняет текущий ID и признак намеренной остановки;
утром после A+B предлагается продолжить тот же поход. В выключенном интервале записей
нет, на карте разрыв; длительность записи и общий календарный интервал различаются.
Само включение после ночёвки не означает согласия на продолжение.

Приложение для первого этапа завершает поход, но не отключает питание дистанционно.
Отдельное удалённое выключение не требуется для этого сценария и не утверждено.
Если прибор завершил поход и выключился до доставки ответа, телефон сохраняет
«Результат не подтверждён» до получения устойчивого результата при следующей связи.
Потеря соединения после команды не служит подтверждением физического выключения.

**Внезапное отключение — Q1.** Предложение: при следующем подтверждённом включении
показать незавершённый поход и запросить решение. «Продолжить» сохраняет ID и отмечает
разрыв; «Завершить» закрывает восстановленные данные без нового похода. Время последней
надёжной записи и время решения пользователя хранятся отдельно: точное время разрядки
не выдумывается. Новый поход возможен после разрешения судьбы прежнего, без удаления
его данных. Автоматическое продолжение после сбоя — альтернативный вариант Q1.

Программный restart может физически снять HOLD; автоматическую перезагрузку
EN-схема не гарантирует. Обычное пробуждение из внутреннего энергосберегающего режима
во время похода отличается от потери питания и не должно каждый раз спрашивать о
продолжении. Аварийное аппаратное выключение ранее отложено и здесь не изобретается.
При ошибке SD предложены повтор сохранения и отдельное подтверждённое выключение с
предупреждением о несохранённых данных; последнее не считается успешным завершением.
Этот аварийный путь интерфейса требует отдельного согласования перед реализацией.

## Повторы, восстановление и ошибки: условия реализации S4

- Один открытый поход на устройство. Общая очередь операций для кнопок и BLE;
  одновременный START с двух сторон создаёт максимум один ID. Устройство отклоняет
  действие с устаревшим ожидаемым состоянием и возвращает актуальное.
- Устойчивый ID независим от UTC; корректировка часов не создаёт/переименовывает поход.
  START/RESUME/END имеют ID операции и ожидаемую ревизию. Повтор END возвращает
  прежний результат; повтор START после перезагрузки не создаёт новую запись.
- Приложение сохраняет незавершённую операцию до отправки. При потере ответа,
  перезапуске или смене устройства сначала запрашивает состояние/результат у нужного
  прибора. Новая команда не подменяет неизвестный результат старой.
- Подтверждение означает устойчивую запись перехода, не просто получение BLE-пакета.
  После сбоя между сохранением и ответом восстановить тот же результат. При сбое
  до завершения записи не объявлять завершённым. Конкретный формат журнала и порядок
  SD/NVS предстоит спроектировать; неоднозначность восстановления показывать явно.
- Ошибка хранения во время похода не даёт показывать «запись надёжно сохраняется».
  Поход остаётся открытым, ошибка и последний сохранённый номер видимы. Возобновление
  после исправления — тот же ID с обозначенным пропуском. PSRAM не равно сохранению.
- Текущее накопление до 15 точек/900 с на стоянке не является допустимым бюджетом
  потери для продукта. Частота сохранения и допустимая потеря — открытый Q5.
- Подключение телефона сначала получает снимок состояния и поддерживаемые операции,
  затем включает кнопки. Старому клиенту нельзя командами RECORD/NEW_HIKE незаметно
  возобновлять завершённый поход. Для несовместимой пары — пояснение и запрет новых
  управляющих действий. Числа команд, версия протокола и схема миграции ещё не выбраны;
  [protocol.md](protocol.md) по-прежнему описывает действующий протокол.
- Если после загрузки журнал недоступен/повреждён, состояние обозначается как
  неизвестное с ошибкой хранения. Нельзя принимать отсутствие читаемого журнала за
  отсутствие открытого похода и начинать новый поверх него. Восстановление такой
  ошибки требует отдельной процедуры, не автоматического удаления данных.
- Старые записи без признака END показываются как записи без подтверждённого окончания.
  Не угадывать завершение по возрасту. Это совместимость формата, не отменённый импорт
  старой установки ради смены ключа. Правила защищённых от удаления походов сохраняются.

## Проверки готовности и границы этапов

| Проверка после реализации | Ожидаемый результат |
|---|---|
| A одна, отпускание до конца A+B, залипшая A | Нет похода/меток; известное аппаратное удержание питания не скрыто |
| Старт из меню и телефона одновременно; повтор/потеря ответа; перезапуск приложения | Один ID и восстанавливаемый результат |
| Старт без GPS и старт без SD | В первом случае запись с неизвестной координатой, во втором понятный отказ |
| BLE оборван во время записи/завершения, телефон закрыт, следующий запуск через месяц | Нет ложного окончания или заявления о живой записи; сохранённые данные доступны |
| END сохранён, ответ потерян; питание пропало до/после сохранения END | Состояние восстанавливается по журналу; завершённый поход не возобновляется |
| Штатное выключение на ночь, внезапный сбой, недоверенные часы | Применяется выбранный Q1/Q2; старый ID сохранён; неизвестный интервал отмечен |
| SD заполнена/отказала, питание просело во время записи | Нет ложного успеха; известна последняя надёжная запись и измеренный объём потери |
| Гашение/разблокировка, удержание B при входе в подтверждение, дребезг | Нет случайного END/выключения/метки; запись продолжается при блокировке |
| Закрытый поход получен не полностью, затем синхронизация продолжена | Он остаётся завершённым; отдельно меняется полнота копии |

До новых деталей: согласование этой модели; затем отдельные задачи S4 по хранению/
протоколу и S5 по приложению. После получения V2: драйвер LCD/RTC, обработка кнопок,
HOLD и реальные проверки отключения, тока, SD, звука и интерфейса (H1).
Эта спецификация не утверждает готовность прошивки V1 к V2 и не запускает выпуск APK.

## Решения для согласования

| Вопрос | Текущее предложение | Статус |
|---|---|---|
| Q1: после внезапного перезапуска | Спросить «Продолжить / Завершить»; альтернативно авто-продолжение того же ID | Вопрос задан владельцу; ответа пока нет |
| Q2: выключение на ночь | Разрешить отдельно от завершения, с сохранением ID | Вопрос задан владельцу; ответа пока нет |
| Раскладка кнопок, блокировка и выдержки | Таблица выше; проверить на макете и с новым пользователем | Не утверждены |
| Ошибка сохранения при выключении | Повтор; отдельное осознанное выключение с предупреждением | Не утверждено |
| Q4/Q5, GPS-политика и первый выпуск | Остаются в основном программном плане | Этим документом не утверждены |
