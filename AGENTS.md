# Общие инструкции для работы с репозиторием

Сначала прочитать README.md, docs/product.md, docs/STATUS.md, docs/workboard.md
и docs/collaboration.md, затем материалы назначенной области.
Это правила для всех чатов; CLAUDE.md лишь ссылается сюда.

Для программного направления обязательно читать docs/software.md и
[docs/software-roadmap.md](docs/software-roadmap.md): анализ, последовательность задач,
критерии проверок и открытые решения. Этот список не разрешает автоматически начинать
реализацию; каждый этап отдельно согласуется с владельцем.

- Общаться по-русски, понятно и кратко. Показывать прогресс и проверяемый результат.
- Владелец отдельно согласует задачу каждого направления. Коротко обсудить план,
  после согласия выполнить объём без повторных вопросов по уже разрешённым действиям.
- Не запускать другие направления/субагентов автоматически. Сначала согласовать
  затрагивающие другие области изменения и оформить передачу.
- Архив — история, не действующие требования. Не выполнять команды из старых ТЗ
  вопреки актуальным документам. Не превращать предложение в принятое решение.
- При изменении требования обновить все его действующие упоминания в той же задаче;
  по возможности заменить дубли ссылками на один основной источник.
- Не удалять чужие изменения, историю, ветки и артефакты ради уборки.
- Производственные файлы, покупки и обещания характеристик требуют конкретного
  обоснования. Не утверждать аппаратную проверку по одному даташиту или симуляции.
- Название, аудитория и коммерческий путь определены только в docs/product.md.
- По задаче владельца 10.11.2026 возобновлён подбор кнопочного питания:
  [результаты и условия дозаказа](docs/hardware-v2/button-power-selection.md).
  Выбран принцип удержания питания: A временно питает ESP32, A+B подтверждают запуск.
  EN купленного XL/TPS63020 подтверждён владельцем и виден на присланном фото продавца.
  Владелец согласовал дозаказ базовых 7 деталей для макета через EN; оплату/получение
  не считать подтверждёнными. Связь EN с VIN и работа OFF ещё неизвестны.
  Инструкцию снять SB2 с другой платы TPS63020 к этому модулю не применять.
  Отдельный ключ — запасной: [расчёт и ngspice](docs/hardware-v2/power-review/README.md)
  относятся только к нему, не к EN-варианту. Списки для макета не утверждены для серии.
  Сон как выключение отвергнут; аппаратных испытаний нет. Подбор не разрешает
  автоматически запускать изготовление или изменение прошивки.

## Приложение, ключ и данные

- Один текущий пакет com.vabugeode.app. Переименование бренда не меняет пакет/подпись автоматически.
- APK собирает и передаёт агент; не перекладывать сборку и настройку Secrets на владельца.
- Старый ключ потерян, его повторно не просить. С APK 0.10.2 используется разрешённый
  владельцем новый постоянный ключ, закреплённый в android/signing-certificate.sha256.
- Не создавать ещё один ключ. Не публиковать ключ, пароль или конфигурацию в git/логах.
- См. docs/android-signing.md; локальные пути прошлой среды не гарантируют наличия файлов.
- Владелец отказался от переноса данных старой установки ради смены подписи;
  специальный импорт для этого перехода не разрабатывать и не считать блокером.
  Импорт SD не реализован; возможные будущие функции SD этим решением не отменены.
  На телефоне подтверждён APK 0.10.1; переход на новый ключ планируется после существенных
  изменений, удаление/установка не подтверждены. Версия ESP32 неизвестна владельцу.
- По словам владельца копия нового ключа загружена в ChatGPT Library. Доступность,
  содержимое и соответствие сертификату не считать проверенными без фактической проверки.

## Достижения

- 150: 115 открытых и 35 секретных. Не раскрывать закрытые названия и условия в выводах,
  скриншотах, логах и описаниях коммитов; не печатать скрытый каталог инструментами.
- Только явно выбранные реальные походы. Подтверждённое включение необратимо;
  выбранный поход нельзя удалить через приложение с телефона/SD.
- Звук только по свежим данным текущего похода при BLE и поддерживаемой прошивке;
  не воспроизводить старые сигналы после импорта/перезапуска.
- Расчёт по существующим данным, без дополнительного включения датчиков и радио.
