# Сборки APK и ключ подписи

Пользователь выбрал: агент сам собирает подписанные APK и передаёт готовый файл.
Не просить пользователя настраивать GitHub Secrets, запускать сборку или подписывать APK вручную.

- Приложение одно: `com.vabugeode.app`, имя `vabuGEOde`.
- Всегда использовать существующий постоянный release-ключ; не генерировать замену.
- Ключ и конфигурация этой облачной среды находятся вне git:
  `/workspace/private-signing/vabugeode-release.p12` и
  `/workspace/private-signing/github-secret.txt`. Пароль не печатать и не коммитить.
- Сборка здесь: `source /workspace/tooling/activate.sh`, затем
  `python3 android/tools/build_signed_apk.py`. Скрипт сам находит сохранённую конфигурацию.
- Публичный отпечаток закреплён в `android/signing-certificate.sha256`; готовый APK проверяется скриптом.
- Для обновлений повышать `versionCode`. Передавать APK через GitHub, без приватного ключа и паролей.
- Если новая среда не содержит ключа, восстановить резервную копию владельца. Не обещать сохранность
  файлов между независимыми облачными средами и не создавать APK с другой подписью.

GitHub Actions без Secret проверяет код и тесты; публикация подписанного APK агентом выполняется локально.
Подробнее: `docs/android-signing.md`.
