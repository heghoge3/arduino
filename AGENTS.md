GPS-исправление 0.1.18 совместимо с установленным APK 0.10.1. Сохранить приложение и данные.

Пользователь выбрал: агент сам собирает подписанные APK и передаёт готовый файл.
Не просить пользователя настраивать GitHub Secrets, запускать сборку или подписывать APK вручную.

- Приложение одно: `com.vabugeode.app`, имя `vabuGEOde`.
- Всегда использовать существующий постоянный release-ключ; не генерировать замену.
- Ключ и конфигурация этой облачной среды находятся вне git:
  `/workspace/private-signing/vabugeode-release.p12` и
  `/workspace/private-signing/github-secret.txt`. Пароль не печатать и не коммитить.
- Сборка здесь: `source /workspace/tooling/activate.sh`, затем
  `python3 android/tools/build_signed_apk.py`. Скрипт сам находит сохранённую конфигурацию.
- Публичный отпечаток закреплён в `android/signing-certificate.sha256`; готовый APK проверяется скриптом.
- Для обновлений повышать `versionCode`. Передавать APK через GitHub, без приватного ключа и паролей.
- При наличии резервной копии восстанавливать только тот же ключ. Сейчас такой копии нет
  (см. состояние выше). Не обещать сохранность файлов между независимыми облачными средами
  и не создавать APK с другой подписью как якобы совместимое обновление.

GitHub Actions без Secret проверяет код и тесты; публикация подписанного APK агентом выполняется локально.
Подробнее: `docs/android-signing.md`.

# Достижения

- 150 всего: 115 открытых по возрастанию редкости, 35 секретных в конце.
- Не раскрывать пользователю закрытые секретные названия и условия, в том числе в логах,
  скриншотах и описаниях коммитов/релизов. Не выводить полный скрытый каталог инструментами.
- Только явно выбранные реальные походы: «Учитывать в статистике» изначально выключено.
  Подтверждённое включение необратимо; поход нельзя удалить с телефона или SD через приложение.
- Уведомления — в приложении и Android. Короткий зуммер — только по свежим данным текущего похода,
  при BLE и прошивке от 0.1.17; не воспроизводить поздние сигналы после импорта или перезапуска.
- Расчёт офлайн по существующей телеметрии, без включения гироскопа/компаса и без усиления радио.
