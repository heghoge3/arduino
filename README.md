# ПОЛИМЕР для Android 0.10.15

Подписанная сборка от 27.11.2026. Пакет `com.vabugeode.app`, versionCode 38. Совместима с установкой поверх 0.10.14 с тем же постоянным сертификатом.

- Главная сразу показывает сохранённые показания с временем замера.
- В разделе «Гаджет» добавлено отдельное окно диагностики с журналом и счётчиками.
- На графиках видно время последнего замера и есть стрелка прокрутки показателей.
- В истории реальные походы идут перед сворачиваемыми демо-записями. Многодневные походы показывают обе даты.
- Карта занимает доступную высоту. Список меток открывается снизу.

Проверка Android — 181 автоматический тест. Расширенная оценка высоты по барометру, GPS и стоянкам требует прошивки V2 0.1.34. В APK включён опубликованный OTA-образ 0.1.32 / wiring2.
