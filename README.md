# ПОЛИМЕР для Android 0.10.17

Подписанная сборка от 27.11.2026. Пакет `com.vabugeode.app`, versionCode 40. Подписана тем же сертификатом, что и 0.10.16.

- Закат и рассвет остаются справа от температуры при появлении минуса. Плитки показаний выровнены по высоте в каждой паре. Дельта давления использует цвет показателя.
- На главной появился сегментный индикатор заряда и уточнена подпись времени до разряда.
- На вкладке «Гаджет» добавлены индикаторы связи, записи и SD.
- В истории походов обновлены карточки и детали. Имя по умолчанию содержит дату начала. У завершённого похода нейтральная подпись. Экспорт в CapCut удалён.

Проверка Android прошла на 183 автоматических тестах. Для прогноза по среднему току автономной работы на реальном гаджете потребуется отдельное обновление прошивки. Встроенный OTA-образ предназначен для 0.1.32 / wiring2.
