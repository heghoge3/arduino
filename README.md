# ПОЛИМЕР для Android 0.10.19

Подписанная сборка от 28.11.2026. Пакет `com.vabugeode.app`, versionCode 42. Сертификат совпадает с сертификатом 0.10.18.

- История походов показывает компактные карточки с миниатюрами маршрутов.
- На карте расстояние и время выровнены, значок источников стоит рядом с подписью карты.
- У экрана температуры сине-серый ободок. Начало и завершение похода подтверждаются свайпом.
- Квадратная кнопка рядом с завершением ставит измерения на паузу и возобновляет их. Пауза сохраняется после неожиданного перезапуска. На графиках и карте виден разрыв записи.

Полная пауза доступна в эмуляторе и на гаджете с прошивкой 0.1.35 или новее. Встроенный OTA-образ относится к прошивке 0.1.32 / wiring2.

Прошли 188 автоматических тестов Android и 121 тест прошивки.
