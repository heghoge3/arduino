# vabuGEOde 0.1.19

vabuGEOde 0.1.19 — восстановление GPS без ложных красных точек

Сборка s3 для реального ESP32-S3-Zero. Включает исправления 0.1.18.
Совместима с установленным APK 0.10.1. Переустановка APK не требуется.

После подмены прежняя проверка 10 секунд сохраняется. Пока идёт ожидание,
координаты не принимаются в GPS-трек, но новые записи не рисуются красными
и не увеличивают счётчик подмены. Чёрный список и действующие проверки сохранены.
Шаги и приблизительная дистанция продолжают считаться.

Старые POINT на SD и в телефоне не переписываются. В APK 0.10.1 старые красные
точки ожидания останутся видны. Исходники APK 0.10.2 обрабатывают их отдельно,
но подписанного APK пока нет из-за утраты прежнего ключа.

Установка на существующий гаджет с прежней разметкой huge_app:
  python -m esptool --chip esp32s3 --port <ПОРТ> write_flash 0x10000 firmware.bin
<ПОРТ> заменить портом устройства. Это файл раздела приложения, не полный flash.
Не записывать firmware.bin по адресу 0x0000. Полное стирание не требуется;
при обновлении только раздела приложения настройки NVS и файлы SD сохраняются.
Перед USB выключить батарейную ветвь, как в прежних инструкциях питания.
После прошивки подключить установленное приложение для сверки времени.

Вариант для сборки/загрузки PlatformIO — s3 (не s3_fake).
Это обновление через USB; Bluetooth OTA этой версией не добавляется.

Проверено: 45 тестов ядра, 29 Android-тестов, сборки s3 и s3_fake.
Проверок на физическом устройстве в этой среде не было.
Исходники: fix/gps-phone-false-positive, коммит e3b4eca.
source.patch содержит изменения от базового 3643bd2 до e3b4eca.
