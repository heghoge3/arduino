# vabuGEOde 0.1.18 — исправление GPS

Сборка s3 для ESP32-S3-Zero. Совместима с установленным APK 0.10.1.
Исправлены ложные срабатывания из-за старой позиции телефона и расхождения времени.
В архиве — firmware.bin (раздел приложения, 0x10000), инструкции, разбор и исходный патч.
Это промежуточное исправление пункта GPS. APK в архив не входит.

Исходники: ветка fix/gps-phone-false-positive, коммит 748d1f6.
Проверено: 44 теста ядра, модель DS1302, 25 Android-тестов, сборки s3 и s3_fake.
