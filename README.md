# vabuGEOde

Походный трекер: ESP32-S3 + GPS + датчики → SD-карта и приложение на телефоне по Bluetooth.
Полное ТЗ — в [CLAUDE.md](CLAUDE.md).

## Структура

- `docs/protocol.md` — протокол BLE между устройством и телефоном; `docs/protocol_vectors.json` — эталонные пакеты.
- `android/` — приложение (Kotlin, Jetpack Compose). По умолчанию подключается реальный гаджет;
  для проверки экранов в настройках можно выбрать виртуальное устройство с тем же протоколом.
  Журнал обмена — на вкладке «Трекер».
- `firmware/` — прошивка ESP32-S3 (PlatformIO), см. [firmware/README.md](firmware/README.md).
- `docs/gadget-logic.md` — как устройство живёт: питание, GPS, радио, тревоги, связь с телефоном.

## Как поставить приложение на телефон

1. Открыть вкладку **Actions** в репозитории → последний успешный запуск «Android APK».
2. Внизу в **Artifacts** скачать `vabugeode-apk` (zip), распаковать, открыть `app-release.apk`.
3. Разрешить установку из этого источника, если телефон спросит.

## Сборка локально

**Финальная экономная сборка для похода: прошивка 0.1.16, приложение 0.9.9.**

* GPS рисует реальные принятые точки. Без GPS/при подмене записываются шаги, время и датчики.
  После возвращения GPS привязки соединяются пунктиром; расстояние считается по шагам,
  а не длине прямого пунктира. Внутренние повороты неизвестны. Паузы и переезды не соединяются.
* Гироскоп и измерения компаса отключены. Шаги и пробуждение от движения сохранены.
  Инерциальные разработки не потеряны: ветка `archive/inertial-pdr-0.1.15`,
  [заметка о дальнейшей работе](docs/deferred-inertial-navigation.md).
* Без GPS: вкладка «Карта» → «Задать старт без GPS» → выбрать на карте или ввести координаты.
  Старт показан отдельным цветом и помечен как ручной, он не считается подтверждённым GPS.
  В настройках доступно начало от свежей позиции телефона. Новые координаты до возврата GPS
  не выдумываются; шаги продолжают накапливаться.
* Настройки → «Поправка температуры»: −20…+20 °C, шаг 0,1. Например, при завышении на 3° задать −3.
  Сохраняется на гаджете, применяется к новым значениям и без телефона. Исходная температура
  сохраняется отдельно; старые графики не пересчитываются. Сверять с термометром рядом после
  стабилизации. Постоянная поправка не компенсирует любой меняющийся нагрев корпуса.
* Стандартный радиус запрещённых точек теперь 5 км (диаметр 10 км), включая миграцию старых
  значений по умолчанию. Явные пользовательские диаметры сохраняются. Исправлена загрузка
  многострочного JSON с SD. Старые GPS-точки внутри текущих зон исключаются из отображаемой
  геометрии, но исходные записи не удаляются. Фильтр подмены не гарантирует обнаружение любой атаки.
* Исправлено восстановление шагов/километража при продолжении похода после полного перезапуска,
  отображение старой скорости/высоты при потере фикса и защита ручной привязки от старой догрузки.

Приложение снова одно: **vabuGEOde**, пакет `com.vabugeode.app`. Версия 0.9.9 подписывается
постоянным ключом владельца; будущие версии с этим же ключом и большим `versionCode`
устанавливаются как обновление. Старую debug-версию перед первой установкой release нужно удалить:
это удаляет её локальные походы и импортированные карты, но не записи гаджета на SD.
По решению владельца тестовые данные старой версии сохранять не требуется.
Отдельный вариант «Поход» больше не собирается. При первом запуске выбран реальный гаджет.
APK из Actions: **vabugeode-apk** → `app-release.apk`.
Ключ и пароли не хранятся в исходниках или кэше; настройка постоянной подписи описана
в [docs/android-signing.md](docs/android-signing.md). До настройки Secret Actions не публикует APK.

Перед выездом обновить **обе** части, начать отдельный поход и проверить запись/догрузку с SD.
[Короткая проверка на устройстве](docs/deferred-inertial-navigation.md#короткая-проверка-перед-походом).
Автономность и расход финальной сборки требуют измерения на реальном устройстве; часы в приложении
приблизительны. На программных тестах нельзя подтвердить влагозащиту, контакты и срок работы батареи.

В 0.9.5 во вкладке «Походы» есть «Завершить и начать новый поход». Старый поход остаётся архивом.
В его деталях «Удалить» по умолчанию удаляет трек и метки также с SD выбранного подключённого гаджета;
копия в телефоне удаляется только после подтверждения. Можно явно снять флажок и удалить только
из телефона. Текущий поход удалять нельзя. Для управления SD нужна прошивка 0.1.13.
Без SD новый поход этой командой не начинается: сначала нужно сохранить предыдущий на исправную карту.

Под большими графиками появились условные пояснения за последние 30–60 минут: 7–8 вариантов
для каждого показателя, включая совместные изменения температуры, давления и влажности.
Короткие ряды, разрывы более 5 минут и недостаток показаний не интерпретируются.
Если подходящего условия нет, строка отсутствует. Это объяснение измерений, не точный прогноз погоды.

В приложении 0.9.4 большие графики во вкладках «Графики» и «Походы» масштабируются
двумя пальцами или кнопками +/−. При увеличении горизонтальный свайп перемещает видимый
период, вертикальный оставляет прокрутку страницы. Кнопка сброса возвращает весь период;
касание показывает значения. Масштаб времени ограничен 64× и минимальным окном в минуту.
Шкала значений автоматически подстраивается к видимому участку. Мини-графики остаются обзорными.

В приложении 0.9.3: Настройки → «Чёрный список подмены» → «Изменить диаметр» у нужной точки.
Диаметр вводится в километрах (0,2–100), отдельно для каждой области; исходный диаметр — 2 км
(радиус 1 км). Изменение сохраняется на телефоне и отправляется гаджету при активном соединении
либо следующем подключении. Большая область исключает из трека также настоящие позиции внутри неё.
Прошивка использует существующую команду BLACKLIST; обновление прошивки ради этого поля не нужно.

```
cd android
./gradlew assembleDebug testDebugUnitTest
```

Тест `ScreenshotTest` рисует экраны с демо-данными в `android/app/build/screenshots/`.
