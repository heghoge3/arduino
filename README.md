# ПОЛИМЕР для Android 0.10.16

Подписанная сборка от 27.11.2026. Пакет `com.vabugeode.app`, versionCode 39. Подписана тем же сертификатом, что и 0.10.15.

- У температурного дисплея появился тёпло-серый кант и слегка выпуклое стекло.
- При свежем замере подсвечиваются изменившиеся цифры.
- Начало и продолжение похода выделены зелёным, завершение красным. Время восхода или заката показано рядом с отсчётом до него.
- Нижняя навигация стала матовой. Стиль осциллографа применяется ко всем графикам. Температура на графиках отображается по показаниям датчика.

Проверка Android прошла на 183 автоматических тестах. Встроенный OTA-образ предназначен для 0.1.32 / wiring2.
