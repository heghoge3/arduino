# ПОЛИМЕР для Android 0.10.14

Подписанная сборка для проверки, versionCode 37, пакет `com.vabugeode.app`. Устанавливается поверх 0.10.13.

- Новое название «ПОЛИМЕР» под иконкой, в пиксельной шапке, на экранах подключения и в уведомлениях.
- Проверка обновления прошивки запускается только для реального гаджета. При подключении эмулятора предупреждение «не поддерживается» исчезло в тестах.
- Пройдены автоматические проверки переключения на эмулятор и запуска с сохранённым виртуальным походом. Вылет на телефоне требует проверки на устройстве.

Встроенный образ ESP32 — 0.1.32 / wiring2.
