# ПОЛИМЕР для Android 0.10.18

Подписанная сборка от 27.11.2026. Пакет `com.vabugeode.app`, versionCode 41. Сертификат совпадает с сертификатом 0.10.17.

- Графики переключаются через мини-графики. Экран без замеров показывает состояние похода и подсказывает следующее действие. График заряда сглаживает колебания внутри непрерывной записи.
- На главной показания гаджета подписаны по строкам. Кнопка подключения упрощена. В истории и деталях похода выровнены даты и итоги. На карте позиция и кнопка меток собраны в одной панели.
- На вкладке «Гаджет» статусы расположены вертикально. В диагностике используется стрелка назад. Android запрашивает разрешения при первом запуске, а недостающие разрешения видны на вкладке «Гаджет».

Прошли 187 автоматических тестов. Встроенный образ OTA предназначен для прошивки 0.1.32 / wiring2.
