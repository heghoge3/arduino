# vabuGEOde 0.10.0

Готовый подписанный APK, пакет com.vabugeode.app, versionCode 23. Подпись совпадает с 0.9.9: устанавливать поверх.

100 достижений (80 открытых и 20 секретных). Походы → Достижения. Учитываются только явно выбранные походы: галочка по умолчанию выключена, подтверждённое включение необратимо, удаление такого похода через приложение запрещено.

Прошивка 0.1.17 нужна для короткого сигнала зуммера при BLE. С 0.1.16 достижения работают без звука. Для прошивки рекомендуется обычный PlatformIO Upload из исходников, окружение s3.

Исходники: ветка ccr-faf69fbe-vwugry, коммит 6ac0d14. Проверено 103 теста Android и 41 тест ядра, обе сборки ESP32-S3.

Приватный ключ, пароли и данные походов в этой ветке отсутствуют.
